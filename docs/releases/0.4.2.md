# 入墨 0.4.2 测试版

展开笔记默认聚焦正文并弹出键盘，有草稿时光标在末尾，可直接继续写。点击窗外或窗口失焦后释放输入，取消尚未执行的键盘请求；收起后再次展开重新聚焦，重复打开已展开窗口不会抢回外部焦点。设置页按点击输入框进入编辑。

沿用上方紧凑默认布局、缩放、布局记忆与一键重置；使用自动聚焦无需再次重置。
