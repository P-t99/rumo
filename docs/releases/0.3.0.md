# 入墨 0.3.0 测试版

安卓悬浮速记工具，在当前 APP 上方写下想法，直接存入个人 flomo。

## 本版功能

- 贴边竖条和悬浮球切换，分别记忆位置。
- 入口透明度 0–80%，展开后的编辑窗口保持清晰。
- 缩短左滑距离，支持双击标题或空白区域收起，输入框保留双击选词。
- 三个可修改快捷标签，新笔记自动填入默认标签。
- 本地草稿自动保存，发送失败保留；API 加密存储。
- 应用内检查、下载和系统确认更新，复用下载任务与已校验文件。
