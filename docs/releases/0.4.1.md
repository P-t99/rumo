# 入墨 0.4.1 测试版

修复展开悬浮框后妨碍微信等其他 APP 输入的问题。展开不自动抢焦点，点击正文后编辑，点击窗外或失焦后释放；取消过期键盘请求，收起被动窗口不影响外部输入法。

新默认窗口更紧凑、靠上，为普通底部键盘预留空间。已经放得下时键盘开合不改变大小与位置；手动放大或放到下方后确实放不下才兜底调整。

升级后请点击一次“重置”应用新默认布局；API、草稿和标签保留。
